# Umutungo mobile testing results

This folder contains platform-specific test handoffs for the existing Expo mobile app.

- [Android testing](./android-testing.md)
- [iOS testing](./ios-testing.md)

The latest installable Android APK is [Umutungo-android-preview.apk](./mobile-builds/Umutungo-android-preview.apk). EAS built it, then it was re-signed with the local preview key used by the Android project. It uses Android version code 9. A connected phone is still needed for the final install and live-flow check. iOS artifacts are not generated by the Android build.
